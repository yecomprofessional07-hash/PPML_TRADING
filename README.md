Este proyecto es una plataforma interactiva de simulación bursátil, desarrollada íntegramente en Streamlit y Pandas, que permite a los usuarios explorar, analizar y gestionar acciones de distintas empresas mediante datos obtenidos desde una API financiera y respaldados localmente en archivos CSV.

El sistema simula un entorno de inversión donde cada usuario puede iniciar sesión, manejar su presupuesto, comprar o vender acciones, y visualizar métricas relevantes para las acciones a tomar por el usuario.
